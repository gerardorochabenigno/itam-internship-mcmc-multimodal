Here we expand the theory by introducing a Bayesian approach to HMM, the label switching problem and genuine multimodality.

2. Bayesian HMM

The Bayesian approach relies on Bayes’ theorem, which states that the conditional distribution of a set of random variables \(\boldsymbol{\theta}\) given a set of observations \(\mathbf{y}\), called the posterior distribution, is equal to the product of the prior distribution of the parameters \(p(\boldsymbol{\theta})\) and the conditional distribution of the observations given the parameters \(p(\mathbf{y} \mid \boldsymbol{\theta})\), divided by the marginal distribution of \(\mathbf{y}\), \(p(\mathbf{y}) = \int p(\boldsymbol{\theta})\, p(\mathbf{y} \mid \boldsymbol{\theta})\, d\boldsymbol{\theta}\), which ensures that the posterior integrates to one (Gelman et al. 2013, ch. 1):

\[ p(\boldsymbol{\theta} \mid \mathbf{y}) = \frac{p(\boldsymbol{\theta})\, p(\mathbf{y} \mid \boldsymbol{\theta})}{p(\mathbf{y})}. \tag{1}\]

Recall that \(p(\mathbf{y} \mid \boldsymbol{\theta})\), viewed as a function of \(\boldsymbol{\theta}\) for fixed observations, is the likelihood function \(L(\boldsymbol{\theta} \mid \mathbf{y})\). Moreover, since the normalizing constant \(p(\mathbf{y})\) does not depend on \(\boldsymbol{\theta}\), it can be omitted, and Bayes’ theorem can be written as the posterior being proportional to the product of the likelihood and the prior:

\[ p(\boldsymbol{\theta} \mid \mathbf{y}) \propto L(\boldsymbol{\theta} \mid \mathbf{y})\, p(\boldsymbol{\theta}). \tag{2}\]

This last expression is the core of Bayesian inference. In most models of practical interest, the integral defining \(p(\mathbf{y})\) has no closed form and cannot be computed numerically in high dimensions, so the posterior is only available up to a normalizing constant. Several methods have been developed to perform Bayesian inference under this limitation, among which Markov chain Monte Carlo (MCMC) methods stand out given that only require evaluating the unnormalized posterior in Equation 2, since the normalizing constant cancels out when comparing the posterior density at two different values of \(\boldsymbol{\theta}\) (Gelman et al. 2013, ch. 10).

2.1 Parameters and prior distributions of a Bayesian HMM

Recall that an HMM is a state-space model consisting of an observation process \(\{Y_t\}\) and an unobserved Markov process \(\{C_t\}\) taking values in a finite set of states \(\{1, \dots, m\}\) (Zucchini, MacDonald, and Langrock 2016). The realization of the observation process, \(\mathbf{y} = (y_1, \dots, y_T)\), is the data on which the posterior in Equation 1 is conditioned.

The parameters governing \(\{C_t\}\) are the initial distribution \(\boldsymbol{\delta}\) and the transition probability matrix \(\boldsymbol{\Gamma}\), while each of the \(m\) state-dependent distributions, also known as emission distributions, has its own parameters \(\boldsymbol{\eta}_j\), \(j = 1, \dots, m\). We collect all of them in the parameter vector

\[ \boldsymbol{\theta} = (\boldsymbol{\delta}, \boldsymbol{\Gamma}, \boldsymbol{\eta}_1, \dots, \boldsymbol{\eta}_m), \]

so that specifying a Bayesian HMM amounts to specifying a prior distribution \(p(\boldsymbol{\theta})\) over each of these components.

Regarding the initial distribution \(\boldsymbol{\delta}\) if it is stationary, then it can be derived from \(\boldsymbol{\Gamma}\) so it leaves \(\boldsymbol{\theta}\). In this notebook we make the assumption that the Markov process is homogeneous and stationary.

2.1.1 Transition probability matrix \(\boldsymbol{\Gamma}\)

Each row of the transition probability matrix, \(\boldsymbol{\gamma}_i = (\gamma_{i1}, \dots, \gamma_{im})\) for \(i = 1, \dots, m\), is a vector of non-negative entries that sum to one. In other words, it belongs to the probability simplex

\[ \Delta^{m-1} = \left\{ \mathbf{x} \in \mathbb{R}^m : x_j \geq 0,\ \sum_{j=1}^{m} x_j = 1 \right\}, \]

the \((m-1)\)-dimensional set of all probability distributions over \(m\) elements (Boyd and Vandenberghe 2004, 33). A natural choice for the prior for vectors in \(\Delta^{m-1}\) is the Dirichlet distribution, whose support is precisely this set (Frigyik, Kapila, and Gupta 2010). We therefore assume that the rows of \(\boldsymbol{\Gamma}\) are independent and that each follows a Dirichlet distribution,

\[ \boldsymbol{\gamma}_i \sim \text{Dir}(\boldsymbol{\tau}_i), \qquad \boldsymbol{\tau}_i = (\tau_{i1}, \dots, \tau_{im}), \quad \tau_{ij} > 0, \]

with density

\[ p(\boldsymbol{\gamma}_i \mid \boldsymbol{\tau}_i) = \frac{1}{B(\boldsymbol{\tau}_i)} \prod_{j=1}^{m} \gamma_{ij}^{\tau_{ij} - 1}, \qquad B(\boldsymbol{\tau}_i) = \frac{\prod_{j=1}^{m} \Gamma(\tau_{ij})}{\Gamma\left(\sum_{j=1}^{m} \tau_{ij}\right)}, \tag{3}\]

where \(\Gamma(\cdot)\) denotes the gamma function and does not have to be confused with the transition probability matrix \(\boldsymbol{\Gamma}\).

The concentration parameters \(\boldsymbol{\tau}_i\) control the shape of this prior. They determine its mean, \(E[\gamma_{ij}] = \tau_{ij} / \tau_{i0}\) with \(\tau_{i0} = \sum_{j=1}^{m} \tau_{ij}\), and how concentrated it is around that mean: the larger \(\tau_{i0}\), the more informative the prior.

Following (Leos-Barajas and Michelot 2018) and (Gallegos-Herrada, Leos-Barajas, and Rosenthal 2026), we set \(\boldsymbol{\tau}_i = \mathbf{1}_m\) for all rows. Besides its simplicity, this choice treats all states symmetrically, so the prior is invariant to a relabeling of the states; the consequences of this property are discussed in Section 4. Under this choice, Equation 3 reduces to

\[ p(\boldsymbol{\gamma}_i \mid \boldsymbol{\tau}_i = \mathbf{1}_m) = \frac{\Gamma(m)}{\prod_{j=1}^{m} \Gamma(1)} \prod_{j=1}^{m} \gamma_{ij}^{0} = (m-1)!, \qquad \boldsymbol{\gamma}_i \in \Delta^{m-1}. \tag{4}\]

Since this density does not depend on \(\boldsymbol{\gamma}_i\), the \(\text{Dir}(\mathbf{1}_m)\) prior is uniform on the simplex, with the constant \((m-1)!\) being the reciprocal of the volume of \(\Delta^{m-1}\). Uniformity on the simplex, however, does not imply uniformity on each entry: the marginal prior of each \(\gamma_{ij}\) is \(\text{Beta}(1, m-1)\), which places more mass near zero as \(m\) grows. In particular, it favors a priori low persistence in each state, i.e., small values of \(\gamma_{ii}\).

2.1.2 Initial distribution \(\boldsymbol{\delta}\)

Since the entries of the initial distribution \(\boldsymbol{\delta}\) must add to one and are all non-negative, it also has support on the probability simplex \(\Delta^{m-1}\).

We can treat \(\boldsymbol{\delta}\) as a free parameter with its own prior distribution or to assume that the Markov process is stationary, so that \(\boldsymbol{\delta}\) is its stationary distribution.

Stationarity means that the chain is already in equilibrium when the observation process starts, so the distribution of the states does not change from one time point to the next (Zucchini, MacDonald, and Langrock 2016)

\[ \boldsymbol{\delta} \boldsymbol{\Gamma} = \boldsymbol{\delta}, \qquad \sum_{j=1}^{m} \delta_j = 1. \tag{5}\]

When the chain is irreducible, that is, when every state can be reached from any other state within a finite number of steps, the stationary distribution exists and is unique (Sargent and Stachurski 2022, Theorem 4.1.1).

Under the \(\text{Dir}(\mathbf{1}_m)\) prior of \(\boldsymbol{\Gamma}\), this condition holds with probability one: since the Dirichlet distribution is continuous on the simplex, no entry \(\gamma_{ij}\) is exactly zero with probability one, so every state can be reached from any other in a single step. The stationary distribution is then given by

\[ \boldsymbol{\delta} = \mathbf{1}_m \left( \mathbf{I}_m - \boldsymbol{\Gamma} + \mathbf{U} \right)^{-1}, \tag{6}\]

where \(\mathbf{1}_m\) is a row vector of ones, \(\mathbf{I}_m\) is the \(m \times m\) identity matrix and \(\mathbf{U}\) is the \(m \times m\) matrix of ones (Zucchini, MacDonald, and Langrock 2016). Under the stationarity assumption, \(\boldsymbol{\delta}\) is no longer a parameter but a deterministic function of \(\boldsymbol{\Gamma}\), so it requires no prior of its own: its prior distribution is the one induced by the prior on the rows of \(\boldsymbol{\Gamma}\).

In this notebook we assume that the observation process starts when the chain is stationary and hence \(\boldsymbol{\delta}\) is the stationary distribution.

2.1.3 State-dependent distributions

Unlike the transition probabilities, the parameters of the state-dependent distributions do not share a common support, so there is no single prior that applies to every model. However, the choice can be guided by the support of each parameter. For example, real-valued parameters such as means call for priors on \(\mathbb{R}\), while positive parameters such as standard deviations or rates call for priors on \((0, \infty)\).

Another criterion for choosing priors is the algorithm used to draw samples from the posterior distribution. Gibbs samplers commonly rely on conjugate priors, which yield posterior conditional distributions in closed form given the hidden states. Stan, which we use later in this notebook, does not require conjugacy, so priors can be chosen for what they express rather than for their algebraic convenience.

When the state-dependent distributions are normal, the conjugate choice is a normal prior on each mean \(\mu_j\) and an inverse-gamma prior on each variance \(\sigma_j^2\) (Gelman et al. 2013). However, inverse-gamma priors with small parameters can be highly influential when a state has few observations, so weakly informative priors on the standard deviation, such as a half-normal or half-\(t\) distribution, are often preferred (Gelman 2006; Leos-Barajas and Michelot 2018). When the observations are counts modeled with a Poisson distribution in each state, a gamma prior on each rate \(\lambda_j\) is a natural choice, both because it is conjugate and because it has the appropriate support, although in Stan only the latter matters.

In this notebook we work with normal state-dependent distributions and use

\[ \mu_j \sim \mathcal{N}(\mu_0, s_0^2), \qquad \sigma_j \sim \text{half-}\mathcal{N}(0, s_1^2), \qquad j = 1, \dots, m. \tag{7}\]

Two features of these priors are important for what follows. First, the same prior is assigned to the parameters of every state, as was done for the rows of \(\boldsymbol{\Gamma}\), so that no state is distinguished a priori. The consequences of this choice are discussed in Section 2.3. Second, the priors are weakly informative rather than vague. In mixture models and HMMs, improper or nearly flat priors on the state-dependent parameters can lead to improper posterior distributions, since there is always a configuration in which some state is assigned no observations and the data provide no information about its parameters (Frühwirth-Schnatter 2006).

2.2 Likelihood via the forward algorithm

The last element needed to assemble the unnormalized posterior distribution is the likelihood. In the previous notebook we showed that, by summing over all possible sequences of hidden states, the likelihood of an HMM can be written as the matrix product

\[ L_T = \boldsymbol{\delta}\, \mathbf{P}(y_1)\, \boldsymbol{\Gamma}\, \mathbf{P}(y_2) \cdots \boldsymbol{\Gamma}\, \mathbf{P}(y_T)\, \mathbf{1}_m^\top, \tag{8}\]

where \(\mathbf{P}(y) = \text{diag}\big(p_1(y), \dots, p_m(y)\big)\) is the diagonal matrix of state-dependent densities evaluated at \(y\) (Zucchini, MacDonald, and Langrock 2016). In the notation of this notebook, \(L_T = L(\boldsymbol{\theta} \mid \mathbf{y})\), and under the stationarity assumption \(\boldsymbol{\delta}\) is the function of \(\boldsymbol{\Gamma}\) given in Equation 6. The forward algorithm evaluates Equation 8 at a cost that grows linearly in \(T\), instead of the \(m^T\) terms of the explicit sum over state sequences. In practice, the recursion is carried out on the log scale, since the product of \(T\) densities quickly underflows to zero (Leos-Barajas and Michelot 2018).

Assuming that the rows of \(\boldsymbol{\Gamma}\) and the parameters of each state are a priori independent, the log of the unnormalized posterior in Equation 2 becomes

\[ \log p(\boldsymbol{\theta} \mid \mathbf{y}) = \log L(\boldsymbol{\theta} \mid \mathbf{y}) + \sum_{i=1}^{m} \log \text{Dir}(\boldsymbol{\gamma}_i \mid \mathbf{1}_m) + \sum_{j=1}^{m} \log p(\boldsymbol{\eta}_j) + \text{const.} \tag{9}\]

No term for \(\boldsymbol{\delta}\) appears, since under stationarity it carries no prior of its own. Each term of Equation 9 corresponds to one statement in the Stan program presented below.

2.3 Exchangeable priors and posterior symmetry

In this section we show that relabeling the hidden states leaves the posterior unchanged. This follows from the likelihood being invariant to the labels and from the priors being exchangeable, that is, treating all states in the same way (Jasra, Holmes, and Stephens 2005). The resulting symmetry is what distinguishes the modes due to relabeling (Section 4) from genuinely different ones (Section 5).

Consider an HMM with \(m\) states and label them state 1, state 2, …, state m. Note that this labeling from a mathematical perspective is irrelevant since the name state 1 initially assigned to a specific state can be assigned to any other state and the same goes to every other state. Under this situation, you can obtain \(m!\) different labelings.

Formally, each relabeling corresponds to a permutation \(\nu\) of the labels \(\{1, \dots, m\}\), and we denote by \(S_m\) the set of all \(m!\) such permutations (Jasra, Holmes, and Stephens 2005). Applying a permutation \(\nu \in S_m\) to the parameters of the HMM yields the relabeled parameter vector \(\nu(\boldsymbol{\theta})\), defined by

\[ \delta'_i = \delta_{\nu(i)}, \qquad \gamma'_{ij} = \gamma_{\nu(i)\nu(j)}, \qquad \boldsymbol{\eta}'_j = \boldsymbol{\eta}_{\nu(j)}, \qquad i, j = 1, \dots, m. \tag{10}\]

where \(\nu \in S_{m}\) is the set of all \(m!\) permutations of \(1,2,...,m\).

For example, with \(m = 2\) there are two permutations, the identity, which leaves the labels unchanged, and \(\nu(1) = 2\), \(\nu(2) = 1\), which swaps them. Applying the latter to Equation 10 gives

\[ \boldsymbol{\delta}' = (\delta_2, \delta_1), \qquad \boldsymbol{\Gamma}' = \begin{pmatrix} \gamma_{22} & \gamma_{21} \\ \gamma_{12} & \gamma_{11} \end{pmatrix}, \qquad (\boldsymbol{\eta}'_1, \boldsymbol{\eta}'_2) = (\boldsymbol{\eta}_2, \boldsymbol{\eta}_1). \]

Both parameter vectors describe exactly the same model, since the state previously called 2 is now called 1, together with its initial probability, its transition probabilities and its state-dependent parameters. Only the names have changed.

Note that relabeling the states does not change the likelihood. To see this, recall that Equation 8 is a compact form of the sum, over all possible \(m^T\) state sequences \((c_1, \dots, c_T)\), of the terms \(\delta_{c_1} p_{c_1}(y_1) \prod_{t=2}^{T} \gamma_{c_{t-1} c_t}\, p_{c_t}(y_t)\). By Equation 10, the term of the sequence \((c_1, \dots, c_T)\) evaluated at \(\nu(\boldsymbol{\theta})\) equals the term of the sequence \((\nu(c_1), \dots, \nu(c_T))\) evaluated at \(\boldsymbol{\theta}\). Since every sequence appears exactly once in the sum, relabeling only reorders its terms, and therefore \(L(\nu(\boldsymbol{\theta}) \mid \mathbf{y}) = L(\boldsymbol{\theta} \mid \mathbf{y})\) for every \(\nu \in S_m\).

To see this, consider \(m=2\) states and \(T=2\) observations. In this case we have 4 possible sequences, so the likelihood is

\[ \begin{aligned} L(\boldsymbol{\theta} \mid \mathbf{y}) =\; & \delta_1\, p_1(y_1)\, \gamma_{11}\, p_1(y_2) + \delta_1\, p_1(y_1)\, \gamma_{12}\, p_2(y_2) \\ +\; & \delta_2\, p_2(y_1)\, \gamma_{21}\, p_1(y_2) + \delta_2\, p_2(y_1)\, \gamma_{22}\, p_2(y_2), \end{aligned} \tag{11}\]

where the four terms correspond to the sequences \((1,1)\), \((1,2)\), \((2,1)\) and \((2,2)\). Now consider the permutation that swaps the labels, \(\nu(1) = 2\) and \(\nu(2) = 1\). By Equation 10, the term of the sequence \((1,2)\) evaluated at \(\nu(\boldsymbol{\theta})\) is

\[ \delta'_1\, p'_1(y_1)\, \gamma'_{12}\, p'_2(y_2) = \delta_2\, p_2(y_1)\, \gamma_{21}\, p_1(y_2), \]

which is the term of the sequence \((2,1)\) in Equation 11.

In the same way, the terms of \((1,1)\), \((2,1)\) and \((2,2)\) evaluated at \(\nu(\boldsymbol{\theta})\) equal the terms of \((2,2)\), \((1,2)\) and \((1,1)\) evaluated at \(\boldsymbol{\theta}\). The four terms are therefore the same, only in a different order, and \(L(\nu(\boldsymbol{\theta}) \mid \mathbf{y}) = L(\boldsymbol{\theta} \mid \mathbf{y})\). Thus, the likelihood is invariant to relabeling of the states.

The prior distribution is also invariant to relabeling, because it treats all states in the same way. Consider again \(m = 2\) and the permutation that swaps the labels. The rows of \(\boldsymbol{\Gamma}\) are exchanged and their entries reordered, but since the \(\text{Dir}(\mathbf{1}_m)\) prior is uniform on the simplex, every row receives the same density before and after the swap. The stationary distribution \(\boldsymbol{\delta}\) is computed from \(\boldsymbol{\Gamma}\), so its entries are swapped as well and no additional term appears.

A prior with this property, which assigns the same density to every relabeling of the parameters, is called exchangeable (Frühwirth-Schnatter 2001; Jasra, Holmes, and Stephens 2005).

Finally, the state-dependent parameters \(\boldsymbol{\eta}_1\) and \(\boldsymbol{\eta}_2\) are exchanged, and since both states share the same prior, the product \(p(\boldsymbol{\eta}_1)\, p(\boldsymbol{\eta}_2)\) does not change. The same argument holds for any \(m\) and any permutation, so \(p(\nu(\boldsymbol{\theta})) = p(\boldsymbol{\theta})\) for every \(\nu \in S_m\). It is important to note, however, if we assign different priors to different states, for instance a prior centered at a low value for \(\mu_1\) and at a high value for \(\mu_2\), this invariance would no longer hold.

Since both the likelihood and the prior are invariant to relabeling, so is their product in Equation 2, and the posterior distribution satisfies

\[ p(\nu(\boldsymbol{\theta}) \mid \mathbf{y}) = p(\boldsymbol{\theta} \mid \mathbf{y}) \qquad \text{for every } \nu \in S_m. \tag{12}\]

A posterior satisfying Equation 12 is said to be symmetric with respect to the labels, since every point \(\boldsymbol{\theta}\) has \(m!\) counterparts \(\nu(\boldsymbol{\theta})\) with exactly the same posterior density.

Although relabeling leaves the posterior unchanged, it becomes problematic in practice when the posterior is explored with MCMC methods. By Equation 12, the marginal posterior distributions of the state-dependent parameters coincide across states, so that, for instance, \(\mu_1\) and \(\mu_2\) have the same marginal posterior. A sampler that has converged to this symmetric posterior therefore moves between the \(m!\) symmetric regions of high posterior density, and averages of state-specific quantities, such as the posterior mean of \(\mu_1\), become meaningless (Jasra, Holmes, and Stephens 2005; Papastamoulis 2016). This phenomenon is known as label switching and is discussed in Section 4.

2.4 Implementation in Stan

To draw samples from the posterior distribution of the HMM we use Stan, a popular open-source probabilistic programming language designed for specifying statistical models and performing Bayesian inference (Carpenter et al. 2017). Models are written in Stan’s own language and can be run from several environments through interfaces such as CmdStanPy for Python, CmdStanR for R and Stan.jl for Julia. In this notebook we use CmdStanPy. Details on installation and usage are available on the official website and in the introductory tutorial by Carpenter (2023).

Stan makes Bayesian inference by using Hamiltonian Monte Carlo (HMC), an MCMC method that relies on techniques from differential geometry to generate transitions spanning the full marginal variance, eliminating the random component of other classes of MCMC algorithms such as Metropolis-Hastings and Gibbs samplers (Betancourt and Girolami 2013).

To illustrate the ideas presented so far, we use univariate data simulated from a 2-state HMM with a moderately persistent transition probability matrix \(\boldsymbol{\Gamma} = \begin{pmatrix} 0.8 & 0.2 \\ 0.3 & 0.7 \end{pmatrix}\), whose stationary distribution \(\boldsymbol{\delta} = (0.6,\ 0.4)\) is used as the initial distribution. The state-dependent distributions are normal with well-separated means, \(\mu_1 = -2\) and \(\mu_2 = 2\), and a common variance \(\sigma^2 = 1\). We simulate \(T = 500\) observations. These values are summarized in Table 1.

Here is the Python code for the simulation but keep in mind that Stan programs require data to be stored in objects.

import numpy as np
import matplotlib.pyplot as plt

# Seed for reproducibility
np.random.seed(0)

# States
m = 2
states = np.arange(m)

# Transition probability matrix
Gamma = np.array([[0.8, 0.2], [0.3, 0.7]])

# Stationary distribution
delta = np.array([0.6, 0.4])

# Observaton process parameters
mu = np.array([-2, 2])
sigma = np.array([1, 1])

# Arrays for the results
T = 500
C = np.zeros(T, dtype=int) # Vector to store the state sequence
Y = np.zeros(T) # Vector to store the simulated data

# Initial values
C[0] = np.random.choice(states, p=delta)
Y[0] = np.random.normal(loc=mu[C[0]], scale=sigma[C[0]])

for t in range(1, T):
    C[t] = np.random.choice(states, p=Gamma[C[t-1]])
    Y[t] = np.random.normal(loc=mu[C[t]], scale=sigma[C[t]])

# Plot the data

Here is the Stan code for the model

stan/02_hmm.stan
// data
data {
  int<lower=1> T;  // number of observations
  int<lower=1> m;  // number of states
  array[T] real y;  // observations, y coincides with the name in stan_data
}

// parameters
parameters{
    array[m] real mu;                   // means of state dependent distributions
    array[m] real <lower=0> sigma;      // standard deviation of state dependent distributions
    array[m] simplex[m] gamma;          // rows of Gamma, gamma[i] is the i-th row 
    
}

// transformed parameters
transformed parameters{
    matrix[m,m] Gamma;
    row_vector<lower=0, upper=1>[m] delta;


    for (i in 1:m){
        Gamma[i] = gamma[i]';
    }
    delta = rep_row_vector(1, m)/(identity_matrix(m) - Gamma + rep_matrix(1,m,m));
}

// model
model{

    vector[m] log_alpha;

    // Prior of the means
    mu ~ normal(0,5);

    // Prior of the deviation
    sigma ~ normal(0,2); // Restriction on sigma guarantees this is half normal

    // Prior of Gamma
    for (i in 1:m){
        gamma[i] ~ dirichlet(rep_vector(1,m));
    }

    // initialize forward log-weights
    for (j in 1:m) {
        log_alpha[j] = log(delta[j]) + normal_lpdf(y[1] | mu[j], sigma[j]);
    }

    // Verosimilitud
    for (t in 2:T){
        vector[m] log_alpha_new;
        for (j in 1:m){
            log_alpha_new[j] = log_sum_exp(log_alpha + log(Gamma[, j])) + normal_lpdf(y[t] | mu[j], sigma[j]);
        }
        log_alpha = log_alpha_new;        
    }
    target += log_sum_exp(log_alpha);
}
